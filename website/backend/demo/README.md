# LastMile AI — Step 4 reproducible demo

This is an **offline synthetic pre-event planning demonstration**. It sends no real alerts and does not certify CAP compliance, legal authorization, or real-world comprehension.

## Requirements

- Python 3.11+ (the project has also been run on Python 3.14).
- Install dependencies from the repository root:

  ```powershell
  python -m pip install -r requirements.txt
  ```

- The approved synthetic workbook must remain at `data/reference/LastMile_AI_Step1_Master_Dataset.xlsx`, together with the approved Step 3 integration code.

## Run from the `LastMile` repository root

```powershell
python demo/run_demo.py --stage T+02
```

This chooses the **T+02:00 cumulative stage** with all five approved channels enabled. Other examples:

```powershell
python demo/run_demo.py --stage T+00
python demo/run_demo.py --stage T+04 --channels CH01 CH03
python demo/run_demo.py --stage T+06 --disable CH02 CH05
python demo/run_demo.py --stage T+02 --output-dir demo_output
```

Valid stages: `T+00`, `T+02`, `T+04`, `T+06`.

Valid channels: `CH01` (SMS), `CH02` (Mobile App), `CH03` (Voice Call), `CH04` (Public Sirens), `CH05` (Digital Signage).

You must keep **at least one channel enabled**. Only the chosen cumulative stage and enabled-channel list are planner-editable. Dataset, warning text, timing parameters and scenario events stay fixed.

## Outputs

The command writes UTF-8 files to `demo_output/` by default:

- `dashboard.html`: open locally in a browser.
- `report.md`: open in VS Code or a Markdown viewer. The report includes the simulation overview, before/after results, tested plans, accessibility/policy findings, and final recommendation.

**Do not commit generated `demo_output` files as source code.** These files can be regenerated by the command above. `--output-dir` can direct outputs to a temporary directory.

### How to interpret the numbers

- **Estimated Reach** counts selected-channel technical arrival (`Delivered` and `Delayed`).
- **Effective Warning Coverage** counts only confirmed timely (up to 30 seconds), individually usable and actionable selected-channel warnings. Public Sirens are alert-only.
- A zero in `P0 Effective Coverage` does **not** mean nobody received an alert or that people failed to understand it. The SMS fixture requires evidence of all segments and individual text usability; unavailable evidence is `Needs Further Review`, not confirmed success.
- **Recovery Improvement** is in **percentage points** over the fixed population of 1,000 synthetic residents. Technical critical cases do not include all accessibility-review cases.
- Results are modeled, deterministic, and scenario-only. The exact figures depend on selected stage and enabled channels.
